# DND 官方 1000 图块：真实自然图像去噪实验工具（Windows）

## 1. 安装位置

将压缩包里的 **`DND_实验工具` 文件夹**放到你之前的目录中：

```
D:\作业\多媒体技术\工程文件\其他真实噪声数据集\
├── DND\
│   ├── images_srgb\
│   │   ├── 0001.mat
│   │   └── ... 0050.mat
│   ├── images_raw\         （本实验不使用）
│   ├── info.mat
│   └── pixelmasks.mat\      （本实验不使用）
└── DND_实验工具\
    ├── run_dnd.py
    ├── 00_安装依赖_只需一次.bat
    ├── 01_DND_检查1000图块.bat
    ├── 02_DND_测试5个图块.bat
    ├── 03_DND_全量1000图块.bat
    ├── 04_DND_重新生成统计.bat
    ├── 05_DND_检查每块像素是否可读_较慢.bat
    └── 输出结果\     （运行后自动创建）
```

**文件夹位置很重要：`DND` 与 `DND_实验工具` 是同级文件夹。** BAT 已自动采用这一相对路径。请勿将两个文件夹嵌套到一起。

## 2. 依次双击运行

1. `00_安装依赖_只需一次.bat`，安装 `numpy / opencv-python / h5py`；已有则跳过。
2. `01_DND_检查1000图块.bat`：检查 50 张 `.mat` 文件、坐标和尺寸；此检查**默认不解码全部图块像素**。
3. `02_DND_测试5个图块.bat`：对 5 个官方图块运行 10 组（输入基线 + 9 种滤波配置），预计 50 条记录。
4. `03_DND_全量1000图块.bat`：处理 50 张 × 20 区域 = 1000 个图块，预计 10,000 条记录；自动断点续跑。
5. 如果运行中断，**直接再次双击 03**，不要清空 `输出结果\DND_全量1000图块`。
6. `04`：在不重复处理图像的情况下重建统计 CSV。
7. `05`（可选）：检查全部 1000 个图块是否能完整解码；较慢，但能查找压缩/文件损坏问题。

如果 Windows 双击显示路径问题，可使用命令行：

```
py -3 -X utf8 run_dnd.py --data "..\DND" --out "输出结果\DND_全量1000图块" --previews 10
```

## 3. 主要输出

在 `DND_实验工具\输出结果\DND_全量1000图块\` 内：

- `逐图逐参数结果.csv`：每张/每块/每组滤波一行，包含实际处理时间与相对变化代理指标。
- `按算法参数汇总.csv`：10 个配置的汇总，给前端直接导入。
- `分图像汇总.csv`：每张原始图片的参数统计，用于场景差异分析。
- `官方图块核验.csv`：保留输入、官方裁剪坐标和尺寸证据。
- `方法参数定义.csv`：方法与参数可追溯。
- `实验完成状态.json`：完整性核对（应为 10000 / 10000、complete_selected=true）。
- `代表性四图对比\`：默认仅保留前十个输入图块的“原图、高斯、中值、双边”四图（已标注各参数）；同时生成 `原始输入图块` 单独 PNG，可直接拖进网页版交互实验台。
- `运行错误记录.csv` / `数据检查错误.csv`：错误定位。

文件采用 UTF-8 BOM 编码，Excel/WPS 通常可直接正确显示中文。

## 4. 评价原则（特别重要）

**本工具永不添加人工噪声。** 数据直接来自 DND 官方 `images_srgb` 中的 `InoisySRGB`，配合 `info.mat` 官方 bounding box 裁剪 512×512 区域。**没有缩放，没有拿带噪输入当作干净真值。**

DND 测试集不公开 GT，故本地 **PSNR、SSIM、MSE 必须保持空值**；它们需要通过官方提交评测才可获得。这里的数值仅是：

- `elapsed_ms`：滤波执行耗时，*不含* MATLAB 文件 IO、裁剪及指标计算。
- `flat_hf_ratio`：输入低梯度区域内，滤波后相对滤波前的 Laplacian 高频能量比。低值表示纹理/高频变化减少，**可能是噪声被抑制，也可能是细节被平滑，不能直接解释成“降噪准确率”**。
- `edge_gradient_ratio`：输入高梯度区域内的平均梯度强度相对比值。仅提示边缘变化，非感知质量的可靠排名。
- `mean_abs_change`：滤波前后的 RGB 像素平均绝对变化，单位 0–255。
- `changed_pixel_pct`：与输入像素 RGB 不完全一致的像素占比，0–100%。

这套评估是 **无参考视觉/纹理变化与耗时分析**，与其他数据集有 GT 的 PSNR/SSIM 结果不能直接比较。无需将 DND 的输入与它自身计算 PSNR/SSIM。

## 5. 正式实验参数

| 方法 | 编号 | 参数 |
|---|---|---|
| 输入基线 | NO_FILTER | 保留原图 |
| 高斯 | G3_s0.8 / G5_s1.1 / G7_s1.5 | k=3,5,7；sigma=0.8,1.1,1.5 |
| 中值 | M3 / M5 / M7 | 3×3、5×5、7×7 |
| 双边 | B5_c20_s3 / B7_c35_s5 / B9_c50_s7 | d=5,7,9；sigmaColor=20,35,50；sigmaSpace=3,5,7 |

与现有 PolyU/SIDD/RENOIR 滤波参数保持一致。处理使用 8-bit BGR、OpenCV 对应滤波函数。图片转 8-bit 时先把官方 0–1 sRGB 映射到 0–255 并四舍五入；此量化与实际参考实现可能有微小差异，应在报告中说明。

## 6. 节省磁盘空间和断点续跑

- 默认 **不保存** 9,000 张滤波 PNG，只保存约十组代表性四图、CSV 和 JSON。
- 可选 `--save-all` 会保存全部处理图，**耗费大量磁盘空间**，不建议当前使用。
- `--limit` 只限制本次选择的前 N 个图块，**测试与全量使用不同目录**，避免将测试计入正式总量。
- CSV 写入时每个图块后 flush；断电后最多需要重算没有写完的某些组合，已有组合根据 sample_id+config 自动跳过。
- 如果换了参数，请使用新的输出目录，不能把不同参数定义却同名配置的结果混在一起。

## 7. 前端导入

打开同 ZIP 内的 `真实图像去噪实验平台_DND已集成版.html`，进入「实验数据」，切换到 **DND**，上传全量输出里的 `按算法参数汇总.csv`。这会显示 10 个参数组的平均运行耗时。界面明确显示 **PSNR/SSIM 暂无 GT、不能计算**。网页是独立离线演示，结果面板的原始统计来自 CSV 而不是 JavaScript 示例图。
