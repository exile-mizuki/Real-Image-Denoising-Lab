# Attribution & image redistribution notice

The comparison images in this directory are **actual output images supplied by the project author** from their experiments with the NIND, PolyU, SIDD and RENOIR datasets. They are not generated illustrations or synthetic-noise tests.

- `NIND_*`: Natural Image Noise Dataset, corresponding individual image licenses should be checked on Wikimedia Commons.
- `PolyU_*`: PolyU Real-World Noisy Images Dataset, Copyright (c) 2018 The Hong Kong Polytechnic University. Academic/non-commercial use restriction is documented by the [upstream license](https://github.com/csjunxu/PolyU-Real-World-Noisy-Images-Dataset/blob/master/License.txt).
- `SIDD_*`: Smartphone Image Denoising Dataset, original authors and terms per the [project site](https://abdokamel.github.io/sidd/).
- `RENOIR_*`: RENOIR real low-light noisy image dataset by J. Anaya and A. Barbu. Some images have a `Reference (unverified)` panel which must not be described as a pixel-aligned GT.

The site `index.html` also embeds thumbnails derived from experiment images. Before publicly redistributing this repository or enabling GitHub Pages, confirm the image-license requirements (including attribution and derivative-image permissions). The numerical CSV data and evaluation scripts are separated from raw datasets. Original datasets are not included.
